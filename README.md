# คู่มือล่า Golden Walnut — Stardew Valley

เช็กลิสต์ Golden Walnut ครบทั้ง **130 ลูก** บนเกาะขิง (Ginger Island) พร้อมวิธีหาแบบละเอียดทุกจุด เป็นหน้าเว็บไฟล์เดียว เปิดคู่กับเกมแล้วติ๊กเก็บความคืบหน้าได้

## ใช้ยังไง

เปิด `index.html` ในเบราว์เซอร์ หรือดูผ่าน GitHub Pages ได้เลย ไม่ต้องติดตั้งอะไร

- ติ๊กช่องเมื่อเก็บวอลนัทจุดนั้นได้แล้ว
- แถบด้านบนบอกยอดรวมแบบเรียลไทม์ (x / 130)
- กดชิปด้านบนเพื่อกรองตามวิธีหา — ขุด / เก็บ / ปริศนา / สุ่ม / เควส / บริจาค
- ความคืบหน้าบันทึกใน `localStorage` ของเบราว์เซอร์ ปิดแล้วเปิดใหม่ก็ยังอยู่ (เก็บเฉพาะในเครื่องตัวเอง ไม่ซิงก์ข้ามอุปกรณ์)

## เรื่องที่คนเข้าใจผิดบ่อย

**ยอดสะสมไม่ลดเวลาใช้จ่าย** — ตัวนับมีสองตัวแยกกัน คือยอด "เคยเก็บได้" (ขึ้นอย่างเดียว) กับยอดคงเหลือในมือ จ่ายให้นกแก้วไปเท่าไหร่ยอดสะสมก็ไม่ลด ประตู Qi's Walnut Room ที่ต้องการ 100 ลูกจึงยังเปิดได้ตามปกติ **ไม่ต้องกั๊กวอลนัทไว้**

**เล่นหลายคน วอลนัทนับรวมกันทั้งเซิร์ฟเวอร์** — ใครเก็บก็เข้ากองกลาง ลูกที่คนอื่นเก็บไปแล้วจะไม่โผล่ให้เราเก็บอีก
